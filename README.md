# 扣子命令白名单助手 CozeWhitelist

用扣子（扣子桌面版）干活时，智能体每跑一条命令都要你手动点一次"允许"，一晚上能弹上百次。这个工具一条命令帮你把常用命令全部设为"始终允许"，弹窗从此清零。Mac 电脑专用，只需复制粘贴，不用懂编程。

## 📥 下载安装

**准备：只装一个东西** —— Node.js（类似播放器之于视频文件，运行本工具必需）

| 步骤 | 怎么做 |
|------|--------|
| ① 装 Node.js | 打开 [nodejs.org](https://nodejs.org/zh-cn)，下载 **LTS 版**，一路"继续"装完 |
| ② 下载本工具 | 点本页绿色 `<> Code` 按钮 → `Download ZIP` → 解压到桌面 |
| ③ 运行 | 打开"终端"（Launchpad 搜"终端"或"Terminal"），粘贴下面的命令，回车 |

> 下载 → 解压 → 终端粘贴一条命令 → 完成

**你想干什么，就复制哪一行**（在终端里先输入 `cd ` 加一个空格，再把解压出来的文件夹拖进终端窗口，回车，然后复制下面任意一行）：

| 你想干什么 | 复制这条命令 |
|------------|--------------|
| **一键免弹窗（推荐）** | `node coze-whitelist.mjs add --preset recommended` |
| 看看哪些命令已经不用弹窗 | `node coze-whitelist.mjs list` |
| 补一条命令进白名单 | `node coze-whitelist.mjs add 命令名` |
| 把某条命令改回"要弹窗" | `node coze-whitelist.mjs remove 命令名` |
| 自动收集新放行的命令并推送更新 | `node coze-whitelist.mjs collect` |

> 运行时扣子会自己关掉再打开一次（大概十几秒），不用管它，属于正常现象。

## ✨ 它能帮你做什么

### 🚀 一键批量放行
- **推荐套餐（recommended）** — 一条命令放行 100+ 条日常开发命令：git、node、python、docker、ssh……覆盖绝大多数弹窗
- **按场景选套餐** — `js`（网页开发）、`python`（数据处理）、`infra`（服务器运维）三个小套餐，也可以单点

### 📋 白名单随时可管
- **随时查看** — 现在哪些命令不弹窗，一条命令列出来
- **随时增删** — 漏了哪条补哪条，后悔了哪条删哪条
- **危险命令拦截** — 删文件的 `rm`、要管理员权限的 `sudo` 这类命令，工具默认拒绝加入；真要加必须多打一个"我知情"的开关（`--yes`）

### 🔒 隐私安全
- **账号信息不落地** — 工具借你扣子的登录状态办事，只在内存里用几秒钟，不保存、不打印、不外传
- **只动你自己的** — 只操作你这台电脑、你这个账号的白名单，碰不到别的
- **代码一眼看全** — 全部功能就在一个文件里，不放心可以自己打开看

## 🏗 它是怎么工作的

弹窗的真相：扣子每跑一条命令，都会问服务器"这条命令允许过吗"，没记录就弹窗问你。点"始终允许"= 在服务器记一条规则。本工具只是**替你批量点"始终允许"**：

```
┌──────────────────────────────────────────────┐
│  你的 Mac                                     │
│                                              │
│  扣子 --(短暂重启,开着本地调试口)--> 读取登录状态 │
│      │                                       │
│      ▼                                       │
│  批量写入"始终允许"规则（调用扣子自己的接口）    │
│      │                                       │
│      ▼                                       │
│  扣子恢复正常模式，弹窗消失 ✅                 │
└──────────────────────────────────────────────┘
```

2. 下载解压本工具

4. 完事。之后用扣子，弹窗基本消失

## 📝 注意事项

- `rm`（删文件）、`sudo`（管理员权限）这类危险命令**故意**不放行：弹出时你点一次"始终允许"就好，这层确认是防智能体闯祸的最后关卡
- 真想连这些也不弹：扣子聊天窗口里有"授权模式"，切到"完全访问权限"就是彻底不问——但删文件也不打招呼，想清楚再开
- 工具用的是扣子的内部接口，官方一升级可能失效，失效了回来这里看新版本
- 目前只支持 Mac；扣子国际版（App 名叫 Coze）可用 `--app-name Coze` 尝试
- 扣子正在跑任务时先别运行本工具，等任务跑完再用
- `collect` 会把你白名单里新出现的命令记进 `collected-commands.json` 并自动提交推送到本仓库，适合配合定时任务做无人值守收集

<details>
<summary><b>⚙️ 高级选项（一般用不到，点开看）</b></summary>

```bash
--port 9222          # 本地调试端口（默认 9222）
--device-id <id>     # 设备号，默认自动读取，多设备用户才需要手动指定
--app-name <名称>    # 应用名，默认"扣子"，国际版传 Coze
--no-manage          # 不自动重启应用（适合自己手动带调试参数启动的人）
--yes                # 免确认；加入高危命令时必须加这个
--json               # 让 list 输出机器可读的 JSON（配合脚本使用）
```

要求：macOS + Node.js ≥ 22 + 已登录的扣子桌面版（cn.coze.desktop）。
工作原理简述：临时以 `--remote-debugging-port` 重启应用，经 Chrome DevTools Protocol 读取本机会话 Cookie（仅内存），调用 `/api/coze_claw/shell_permission` 系列接口完成查询/新增/删除。
